# 代码生成规范

**跨框架说明**：`customStyle` 为 CSS 格式。Web 项目直接使用；非 Web 项目（Flutter、React Native 等）根据目标框架转换为对应样式写法。

## 项目规范检测

生成代码前，检测项目已有代码，遵循相同模式。
按优先级：`agents.md` → `README.md` → `package.json` → 已有代码 → 配置文件

检测项：技术框架、样式方案、路径别名、资源引用方式、命名规范

确定框架和样式方案后，遵循项目已有风格和对应技术框架最佳实践。

```
❌ 假设资源引用方式（如直接用 import）
✅ 检测项目已有组件如何引用资源，遵循相同模式
```

## customStyle 提取

**样式从 `customStyle` 精确提取，不估算、不简化、不添加不存在的属性。**

```
❌ 看截图"大概 12px" → padding: 12px
✅ customStyle 有 "padding": "0 rem(24)" → padding: 0 rem(24)
```

| 检查项   | 说明                                             |
| -------- | ------------------------------------------------ |
| 属性遗漏 | `customStyle` 中每个合理属性都应出现在代码中     |
| 属性多余 | 不添加 `customStyle` 中不存在的属性              |

**跨框架**：`customStyle` 为 CSS 格式。Web 项目直接使用；非 Web 项目根据目标框架转换。

### 语法修正

`customStyle` 可能包含无效 CSS 语法，保留语义、修正语法：

| 场景                                  | 原值                               | 修正                                     |
| ------------------------------------- | ---------------------------------- | ---------------------------------------- |
| background 中 fallback 颜色位置错误   | `url(...) lightgray 0px 0px / ...` | 移除 `lightgray` 或移至 background-color |
| 无效简写组合                          | 根据实际情况                       | 拆分为多个有效属性                       |

## 数据来源

| 来源 | 用于                 | 不用于     |
| ---- | -------------------- | ---------- |
| 截图 | 理解结构、布局方向   | 提取样式值 |
| JSON | 精确样式、文本、尺寸 | —          |

- 文本默认值从 `text.content` 提取
- 多状态设计分别从对应节点的 `customStyle` 提取

## 组件与接口设计

复杂设计拆分为多个组件文件，职责单一。组件设计合理的输入接口，数据驱动渲染。

| 类型         | 判断标准           | 处理方式               |
| ------------ | ------------------ | ---------------------- |
| 业务数据     | 运行时从接口获取   | Props（必填）          |
| 可配置文案   | 复用时可能需要修改 | Props（可选 + 默认值） |
| 固定 UI 文案 | 复用时不会改变     | 硬编码                 |

**Props 结构**：

| 场景               | 设计方式                                  |
| ------------------ | ----------------------------------------- |
| 语义相关的多个字段 | 组合为对象：`user: { name, avatar }`      |
| 重复结构（×N）     | 对象数组：`items: Array<{ title, icon }>` |
| 独立的单一值       | 独立 prop：`disabled: boolean`            |

判断标准：字段是否**总是一起出现、一起变化**？是 → 对象，否 → 独立

重复结构（`repeatCount > 1` 或 `×N`）：用数组 Props + 循环渲染，调用层传入 mock 数据（值来自设计稿）。

## 响应式

组件适配任意父容器宽度，不假设特定屏幕尺寸。

- 容器（有子节点）→ `width: 100%`
- 原子元素（图标、图片）→ 保留固定尺寸
- 有 `padding` 时 → 添加 `box-sizing: border-box`

> 设计稿画板宽度（如 375px）是设计工具约束，不是组件实际宽度。

## 资源处理

所有图标和图片必须下载实际资源，不使用占位符。

### 资源来源（按优先级）

| 优先级 | 来源                          | 说明                           |
| ------ | ----------------------------- | ------------------------------ |
| 1      | **assets 数组**               | 权威来源，全部遍历下载         |
| 2      | customStyle 中的 `url()`      | 图片背景                       |
| 3      | RECTANGLE + object-fit: cover | 隐式图片占位符（无 url 时），用节点 ID 下载 PNG |

### 例外（可用 CSS）

纯色背景、分隔线、渐变（无 `url(<path-to-image>)` 标记）。

下载命令见 [api.md](api.md)。

## 交互状态

| 类型                           | 规则                                             |
| ------------------------------ | ------------------------------------------------ |
| 行为（点击、表单绑定等）       | 允许推断                                         |
| 样式（hover/active/focus）     | 默认不添加，除非设计稿有对应状态或用户要求       |

如需添加交互样式，用最小化方式：`opacity: 0.9` 或 `filter: brightness(0.95)`。

## 常见问题

| 问题               | 解决                                            |
| ------------------ | ----------------------------------------------- |
| 样式与设计稿不一致 | 从 `customStyle` 精确提取                       |
| 图片/图标显示空白  | 用节点 ID 下载资源                              |
| 状态切换尺寸跳动   | 基础状态用 `border: Xpx solid transparent` 预留 |
